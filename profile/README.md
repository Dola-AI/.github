# Dola AI

**AI assistant for Unreal Engine 5.** A desktop app plus an Unreal Editor plugin: describe a task in one chat, and specialist agents act in your open project.

- **Blueprints:** read graphs, add and wire nodes, set variables and components, then compile and save.
- **Editor actions in plain language:** levels, assets and imports, materials, animation, Niagara, UI, audio, Sequencer.
- **Engine API lookup:** code and graphs use classes and nodes that really exist in your engine.
- **C++:** edits in your project's `Source/` folder; you build as usual.
- **Playtesting:** Play in Editor checks and Unreal automation tests reported back in chat.
- **Checkpoints and rollback**, plus approval prompts before risky actions.

Free with your own model API key; monthly plans add Dola-hosted models. Desktop app for Windows, macOS, and Linux. Plugin builds for Unreal Engine 5.7 on Windows and Linux editors. Access is rolling out from a waitlist.
